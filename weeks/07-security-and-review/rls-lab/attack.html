RLS Lab Tester

Only test a practice project you own.

This page connects to a Supabase project using its publishable key and tries ordinary read and write operations, so you can see what a stranger with that key could do. Use it only on a project you created and filled with the fake data in setup.sql. Pointing tools like this at a database you do not own is not part of this course and may be illegal.

Your URL and key stay in this browser tab's memory only. Nothing is saved to disk or sent anywhere except your own Supabase project. Close the tab and they are gone.

1. Connect to your practice project

Find both values in the Supabase dashboard: click Connect at the top, or go to Settings → API Keys. Copy the Project URL and the publishable key (it starts with sb_publishable_; on older projects it is the anon key, a long JWT). Never paste a secret key here.

2. Run the attacks

Each button runs one operation with the publishable key and shows the raw result or error. Before fix.sql, all of them succeed. After it, read is limited and writes are blocked.
