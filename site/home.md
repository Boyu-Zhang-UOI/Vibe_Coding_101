## The eight weeks

| Week | Title | You build |
|---|---|---|
| 0 | [Pre-work](/setup/) | Accounts, privacy settings, the safety contract |
| 1 | [Hello, Vibe Coding](/weeks/01-hello-vibe-coding/) | A personal home page, live on the web |
| 2 | [Prompting & Save Points](/weeks/02-prompting-and-save-points/) | A browser game in one hour, with git save points |
| 3 | [Spec First](/weeks/03-spec-first/) | Project 1 from your own one-page spec |
| 4 | [Read It, Debug It, Own It](/weeks/04-read-debug-own-it/) | The Debug Clinic (AI off); Project 1 final |
| 5 | [APIs, Secrets & Servers](/weeks/05-apis-secrets-servers/) | An AI-powered micro-app with a hidden API key |
| 6 | [How Agents Work](/weeks/06-agents/) | "Be the Agent"; your capstone's first agent-built feature |
| 7 | [Security, Data & Review](/weeks/07-security-and-review/) | The RLS Attack Lab; a database for your capstone |
| 8 | [Ship It](/weeks/08-ship-it/) | Capstone polish and the Project Fair |

## The Safe Loop

```text
DESCRIBE ──► PLAN ──► STEP ──► TEST ──► READ ──► COMMIT
goal, context,  ask for a   one small   normal +    read the    save point
constraints,    plan; edit  change      edge case   diff        in git
done when       it first
```

If two fixes in a row fail, stop, start a fresh chat and rewrite the prompt: the **two-strikes rule**. [Printable card](/resources/safe-loop).

## How to use this site

- **Students:** do the [Week 0 pre-work](/setup/) first. Each week, read the overview before class, follow the lab in class, and do the homework after. Keep [troubleshooting](/resources/troubleshooting) and the [glossary](/resources/glossary) handy.
- **Self-paced learners:** follow the weeks in order and budget about six hours a week. When you're stuck, use [tutor mode](/resources/tutor-mode).
- **Instructors:** instructor notes, answer keys and the instructor guide are in the [GitHub repository](https://github.com/Boyu-Zhang-UOI/Vibe_Coding_101).
