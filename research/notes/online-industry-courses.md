## Q1. DeepLearning.AI short courses (Vibe Coding 101 with Replit, Claude Code, Build with Andrew, others) and Andrew Ng's views on teaching everyone to code with AI

### Takeaway
DeepLearning.AI (DLAI) short courses are 1–2 hour video courses of 7–17 lessons. Each lesson runs 1–26 minutes and centers on one or two worked projects, and every course ends in a 7–10 minute graded quiz. The courses are free to audit, and a certificate requires a Pro membership. The line runs from the beginner Replit course (Mar 2025) to the intermediate Claude Code course (Aug 2025), then to a true zero-experience course, "Build with Andrew" (Jan 2026, any chatbot, birthday-card app plus table-tennis game), and a spec-driven development course (2026). Andrew Ng's position over this period: everyone should build with AI now (Nov 2025, Jan 2026), but "vibe coding" is a misleading name for hard intellectual work (Jun 2025), and software fundamentals still separate strong builders from weak ones (Aug–Sept 2026).

**Andrew Ng's views (dated)**
- May/June 2025: at LangChain Interrupt, Ng objected to the term "vibe coding" because it suggests engineers "go with the vibes". He called guiding AI to write software "a deeply intellectual exercise" and said he finds a day of it exhausting. — [Hacker News thread, Jun 2025](https://news.ycombinator.com/item?id=44267060); [Wikipedia: Vibe coding](https://en.wikipedia.org/wiki/Vibe_coding)
- Nov 2025, at Snowflake Build: Ng recommended that "everyone" learn to code and said "Don't code by hand... Get AI to help you to code." Critics quoted by IT Pro: Tal Zarfati (JFrog) on supply-chain risks such as slopsquatting; Chrissa Constantine (Black Duck), who warned overreliance "can lead to shallow learning, fragile codebases, and security risks." IT Pro also cites a Fastly finding that 67% of developers spend more time debugging AI-generated code. — [IT Pro, Nov 14, 2025](https://www.itpro.com/software/development/google-brain-founder-andrew-ng-thinks-everyone-should-learn-programming-with-vibe-coding-tools-industry-experts-say-thats-probably-a-bad-idea); [Entrepreneur](https://www.entrepreneur.com/business-news/google-brain-founder-you-should-learn-how-to-vibe-code/499473)
- Jan 2026: "It is now time for everyone... to build software applications with AI!" — [The Batch, Jan 9, 2026](https://www.deeplearning.ai/the-batch/build-with-andrew)
- Aug 28, 2026 (AI Engineering Skills Map, Part 3): fundamentals remain essential even when agents write all the code. Without them, builders make poor tradeoffs in "latency, availability, consistency, reliability, maintainability, simplicity, and/or cost" without knowing it. The five fundamentals he lists: building full-stack applications, managing data, designing system architectures, making systems secure and reliable, scaling and operating in production. His phrasing: developers who deeply understand how software works "vastly outperform those who vibe code without understanding." — [The Batch, Aug 28, 2026](https://www.deeplearning.ai/the-batch/the-ai-engineering-skills-map-in-detail-software-engineering-fundamentals)
- Sept 2026 Skills Map top level: (i) building and deploying AI applications, (ii) software engineering fundamentals, (iii) using coding agents, (iv) shaping the build. — [The Batch, AI Engineering Skills Map, 2026](https://www.deeplearning.ai/the-batch/the-ai-engineering-skills-map)
- 2026: Ng also wrote a letter on "loop engineering" (nested feedback loops for coding agents) as the skill replacing manual prompt writing. The exact date was not captured. — [Andrew Ng on X](https://x.com/AndrewYNg/status/2071988145667928442)

### Inferences
- The DLAI format fits an 8-week course well as per-week pre-work: a 1–2 h video block with a single worked project, then a live or lab session. Build with Andrew's structure (explain → try in chatbot → download/open → customize → second app → own final project → submit) is a ready template for Week 1.
- Ng's shift from "everyone build now" (Jan 2026) to "fundamentals still matter" (Aug 2026) supports putting light fundamentals in later weeks: data, security, deployment and architecture explained in plain language, with no syntax drills.
- "Beginner" labels are unreliable. Vibe Coding 101 with Replit is marked Beginner but assumes some coding. Build with Andrew is the only DLAI course here designed for true non-coders.

### Gaps
- No DLAI course page gives a formal publication date. Dates come from X/LinkedIn announcements and The Batch.
- Whether "free during beta" still applies to the Replit and Claude Code courses as of Sept 2026 is unclear; the pages still say "free... beta".
- Found no aggregated learner-review data (ratings) for DLAI short courses.
- Did not verify whether Replit's free Starter plan is enough to finish Vibe Coding 101 in 2026.

## Q2. Vendor and platform academies: Anthropic, OpenAI, Google/Kaggle, Microsoft/GitHub, Replit, Lovable, Cursor

### Takeaway
Vendor academies are free, short and tool-specific. They mostly assume some developer background (terminal, Git). The main exceptions are Replit Learn, Lovable Academy, Google's "Vibe Coding for Beginners" and the Kaggle intensive, which are explicitly pitched at non-developers. Free-tier fit varies a lot. GitHub Copilot courses work on Copilot Free, and Google AI Studio and Kaggle work on free Google accounts. Anthropic's Claude Code courses need a paid Claude plan or API key.

## Q3. MOOC and marketplace courses: Coursera (Vanderbilt/Jules White, Scrimba, Google, CU), Codecademy, Scrimba, DataCamp, Udemy, Zero to Mastery, freeCodeCamp, edX

### Takeaway
MOOC platforms carry dozens of short (1–9 h) vibe-coding courses. The most substantial are Vanderbilt/Jules White's Coursera line (Claude Code for developers, and "Build Anything with AI — No Code Required" for non-coders), Scrimba's 5-course "Vibe Coding Essentials" (about 15 h, beginners), and paid bootcamp-style video courses such as Zero to Mastery's 18-hour "Vibe Coding Bootcamp" (8 projects, multi-model, $299). Ratings are generally high (4.4–4.8), but critical reviews repeat the same complaints: too superficial, lecture-heavy, jargon unexplained for non-coders, and paid tool subscriptions needed.

### Cited Findings

**Coursera: Vanderbilt / Dr. Jules White**
- "Claude Code: Software Engineering with Generative AI Agents": labeled Beginner, about 5 h, 6 modules. 1) Scaling Up Software Engineering with Claude Code & GenAI (AI labor, adoption concerns, "Best-of-N" pattern); 2) Generative AI, Claude Code & Code Quality (rubrics, constraints); 3) Building Process & Context in Claude Code (CLAUDE.md, reusable commands, in-context learning); 4) Version Control & Parallel Development (feature branches, git worktrees, subagents); 5) Improving Scalability & Reasoning (feedback loops, token limits, design patterns); 6) Multimodal Prompting & Process. 2 assignments. Rated 4.7/5 (178 reviews), 50,994 enrolled. Requires basic software development and Git experience, and **a paid Claude Code subscription**. — [Coursera, live Sept 2026](https://www.coursera.org/learn/claude-code)

## Q4. Cohort-based, live and bootcamp-style programs: Maven, Campus x Replit, fast.ai/Answer.AI Solveit, O'Reilly/Addy Osmani

### Takeaway
Live cohorts run 3–8 weeks with about 3–5 h/week of combined live sessions, async lessons and tiered homework. Prices range from free events to $1,500 tuition. The one program found with the same shape as the planned course is Campus x Replit "VibeCoding 101": 8 weeks, one live class a week, 4 working apps plus a landing-page portfolio and a flagship project, aimed at non-technical professionals, $1,500. For developers, cohort offerings stress vendor-agnostic "agentic engineering" (context engineering, specs, review, CI) over tool demos. fast.ai's Solveit takes the opposite approach to vibe coding: small-step "dialog engineering."

## Q5. Common patterns: projects built, progression, time per module, handling learners who have never coded

### Takeaway
Beginner courses almost always start with a single-file browser app: a birthday or greeting card, a joke or compliment generator, a small game, or a landing page. They then repeat the same process on a second, slightly harder app, then add persistence, auth, or an API, and finish with deployment and a capstone or portfolio. Short-course lessons run 2–26 minutes. MOOC modules run about 1–2 h. Cohort weeks run about 3–5 h. Courses handle never-coders by removing setup (browser IDEs, chatbots that output one HTML file), teaching a repeatable describe → generate → run → customize loop, and framing the learner as a "director." Reviews show that jargon still trips non-coders.

- A defensible 8-week arc drawn from these patterns:
  1. One-file browser app via chatbot (Build with Andrew style).
  2. Second app with the same loop, plus "director" and prompting skills.
  3. Browser IDE / agent (AI Studio, Replit, Lovable) and a multi-feature app.
  4. Debugging and reading errors.
  5. Data and persistence (DB or file) and personal-data projects.
  6. Git/GitHub, deployment and a portfolio landing page.
  7. Context files, specs and security basics.
  8. Capstone plus demo.
- Two apps per course, using the same method on a second, different project, is nearly universal. It teaches that the process transfers, which matters more than any tool's interface.
- Games (table tennis, Snake, whack-a-mole, reaction game, card game) are the most common "second project" because they give instant visual feedback and need no backend. Forms, trackers and dashboards are the common "useful" projects.

### Gaps
- Few courses publish completion rates or time-on-task data, so actual learner hours per module are unknown.
- Found no course with a "habit tracker" or "chatbot" as a documented flagship beginner project, though To-Do lists, calendar apps and trackers appear.

## Q6. Delivery elements praised or criticized (tool-specificity, shallowness, obsolescence, missing fundamentals)

### Takeaway
Praise goes to short, clear, hands-on courses that let beginners ship something quickly and to instructors who explain plainly. Criticism clusters around five issues:
- "super basic / superficial / all talking" courses.
- Hands-on exercises that break because the tool changed.
- Hidden costs from required paid subscriptions and API credits.
- Unexplained jargon for non-coders.
- A broader worry that vibe coding without fundamentals produces shallow learning, insecure code and learners who can't debug.

### Cited Findings
- Praised: "An empowering course- I never thought I could prompt engineer AI to build software" and "just the right balance of instruction and exercises" (Jules White Claude Code, 2025). — [Coursera reviews](https://www.coursera.org/learn/claude-code/reviews)
- Criticized as shallow or lecture-heavy: "Very superficial. All talking, no hands on assignments" (Apr 2026); "Needs more basics and hands on guidance with screenshare, and less high level benefits" (Feb 2026). — [Coursera reviews](https://www.coursera.org/learn/claude-code/reviews)
- Criticized for breakage and cost: a learner following exact exercise instructions got "errors all over the place" and flagged required Claude subscription and credit costs (Aug 2025). — [Coursera reviews](https://www.coursera.org/learn/claude-code/reviews)
- "Super basic" (CU Vibe Coding Fundamentals, Nov 2025). Positive reviews say learners can now build apps without coding knowledge, and critical ones say non-programmers struggle with unexplained terms. — [Coursera CU reviews](https://www.coursera.org/learn/vibe-coding-fundamentals/reviews)
- Rating spread as a signal: Codecademy's Lovable intro sits at 3.98/5 with 26% three-star ratings, while its Cursor-based "Intro to Vibe Coding" sits at 4.54/5. Scrimba's 5-course specialization is 4.4/5 with about 8.5% at 1–2 stars. — [Codecademy Lovable](https://www.codecademy.com/learn/intro-to-ai-programming-with-lovable); [Codecademy Intro](https://www.codecademy.com/learn/intro-to-vibe-coding); [Coursera Scrimba](https://www.coursera.org/specializations/vibe-coding)
- Obsolescence: vibe coding tools change "every few months", so a course recorded a year ago may show an interface that no longer exists (blog-level source). — [VibeGym blog, 2026](https://vibegym.space/blog/best-vibe-coding-courses-for-beginners)
- Providers respond to obsolescence by revising the Elite AI Assisted Coding curriculum quarterly and refreshing materials each cohort. Anthropic's "Claude Code in Action" has been re-scoped around 2026 features (routines/headless, plugins, verification). — [Maven listing](https://maven.com/kentro/context-engineering-for-coding); [Skilljar](https://anthropic.skilljar.com/claude-code-in-action)
- Learning risks (opinion pieces): beginners stop reading error messages because they paste them into AI; they can't decompose problems when the AI fails ("prompt-dependent learners"); and a hybrid of structured study plus vibe-coded projects is recommended. — [Skorykh blog, 2026](https://skorykh.com/blog/is-vibe-coding-good-for-learning/); [DEV: "Vibe Coding Is Fun — But It Might Be Quietly Ruining Your Learning Journey"](https://dev.to/hamidrazadev/vibe-coding-is-fun-but-it-might-be-quietly-ruining-your-learning-journey-3o9k)
- The same blog genre cites a "2025 Purdue study" finding ChatGPT code vulnerable in 40% of cases. This looks like a misattribution (the widely cited ~40% figure comes from the 2021 NYU "Asleep at the Keyboard" Copilot study). Do not use it without checking the primary source. — [VibeGym blog](https://vibegym.space/blog/best-vibe-coding-courses-for-beginners)
- Industry critics: "Overreliance on AI can lead to shallow learning, fragile codebases, and security risks" (Chrissa Constantine, Black Duck). Supply-chain risks such as slopsquatting and prompt injection (Tal Zarfati, JFrog). — [IT Pro, Nov 2025](https://www.itpro.com/software/development/google-brain-founder-andrew-ng-thinks-everyone-should-learn-programming-with-vibe-coding-tools-industry-experts-say-thats-probably-a-bad-idea)
- HN discussion of fast.ai's "Breaking the spell of vibe coding": skill-atrophy concerns and a view that classical design and architecture knowledge amplifies AI tools. — [Hacker News](https://news.ycombinator.com/item?id=47006615)
- Counterpoint: an XDA writer reports that vibe coding taught them programming "better than any course", because textbook-first learning is slow to produce anything real. — [XDA Developers](https://www.xda-developers.com/used-vibe-coding-to-learn-programming-worked-better-than-any-course/)
- Andrew Ng's own caution: fundamentals let builders see tradeoffs (latency, reliability, cost). — [The Batch, Aug 28, 2026](https://www.deeplearning.ai/the-batch/the-ai-engineering-skills-map-in-detail-software-engineering-fundamentals)

### Inferences
- Reviews reward hands-on, screen-shared, follow-along building over talk about benefits. An 8-week course should be mostly labs, with short concept segments.
- To avoid "outdated quickly", teach a tool-agnostic loop (plan → prompt → run → read the error → verify → commit), keep tool-specific click paths in easily updated handouts rather than recorded video, and plan a per-term refresh.
- Debugging, reading error messages, basic security (secrets, auth, input handling) and "explain this code back to me" exercises answer the most common critiques directly and match Ng's fundamentals argument.

### Gaps
- Found no Reddit threads with substantive learner reviews of specific courses (search returned none). HN coverage was about vibe coding broadly, not particular courses.
- The Class Central review report (the main independent reviewer) could not be retrieved.
- Found no controlled study of learning outcomes from vibe-coding courses.

## Q7. Courses explicitly designed around free tools only

### Takeaway
No major course found is explicitly branded "free tools only". Several are fully doable on free tiers by design or in practice: Build with Andrew (any free chatbot), the Kaggle/Google intensive (free Kaggle and AI Studio accounts), the Google AI Studio codelab up to the deploy step, Microsoft's Copilot courses (Copilot Free stated as sufficient), Replit Learn, and Scrimba's free ChatGPT-based "Learn to code with AI". Courses built on Claude Code explicitly require a paid Claude plan or API key.

### Cited Findings
- Build with Andrew: vendor-agnostic across ChatGPT, Gemini and Claude, plus a built-in DLAI chatbot. Auditing is free; only the certificate needs Pro. — [The Batch](https://www.deeplearning.ai/the-batch/build-with-andrew); [DLAI course](https://www.deeplearning.ai/courses/build-with-andrew)
- Kaggle 5-Day AI Agents Intensive (vibe-coding edition): "100% free". Reported to need only free Kaggle and Google AI Studio accounts. Now self-paced. — [Kaggle](https://www.kaggle.com/competitions/5-day-ai-agents-intensive-vibecoding-course-with-google); [Google blog recap](https://blog.google/innovation-and-ai/technology/developers-tools/ai-agents-intensive-recap-2026/)
- Google AI Studio codelab: building and prototyping are free, and only the Cloud Run deployment step requires billing. — [Codelabs](https://codelabs.developers.google.com/vibe-code-with-gemini-in-aistudio)
- GitHub Copilot CLI for Beginners ("works with GitHub Copilot Free") and MS Learn "Get Started with GitHub Copilot" (Free plan sufficient). — [MS Dev blog, Mar 2026](https://developer.microsoft.com/blog/get-started-with-github-copilot-cli-a-free-hands-on-course/); [MS Learn](https://learn.microsoft.com/en-us/training/modules/get-started-github-copilot/)
- Microsoft "Generative AI for Beginners" can run on Foundry Local (offline, no cloud subscription). — [GitHub](https://github.com/microsoft/generative-ai-for-beginners)
- Replit Learn courses appear to be free. — [Replit Learn](https://learn.replit.com/)
- Scrimba "Learn to Code with AI" is billed as a free ChatGPT course. — [Scrimba](https://scrimba.com/learn/aicoding)
- Vanderbilt "Build Anything with AI" specialization: free tiers of ChatGPT, Claude and Gemini are valid options, but Coursera enrollment is paid (financial aid available). — [Coursera](https://www.coursera.org/specializations/build-anything-with-ai)

- Paid tools required: Anthropic Claude Code 101 (Pro/Max/Enterprise or API key); Coursera "Claude Code: Software Engineering with GenAI Agents" (paid Claude Code subscription). — [Skilljar](https://anthropic.skilljar.com/claude-code-101); [Coursera](https://www.coursera.org/learn/claude-code)
- Paid course access despite free tools: Google's "Vibe Coding for Beginners" on Coursera has no audit option (Coursera Plus or financial aid), and Google Skills offers 35 monthly credits for labs via GEAR. — [Coursera](https://www.coursera.org/learn/vibe-coding-for-beginners-from-zero-to-app); [Google Skills](https://www.skills.google/)
- Secondary claim: AI Studio is the only major full-stack vibe-coding tool with a "truly usable free tier" (as of Apr 2026), vs $20–25/mo for Cursor, Bolt and Lovable. Unverified. — [BuildFastWithAI](https://www.buildfastwithai.com/blogs/google-ai-studio-vibe-coding-guide)

### Inferences
- The free-tier opening is real: most beginner curricula either assume one paid platform (Replit, Lovable, Cursor, Claude Code) or are free but very short (under 2 h). An 8-week, multi-tool, free-tier-first design (chatbot → AI Studio or Replit/Lovable free → Copilot Free in VS Code/Codespaces → Gemini CLI or Copilot CLI) would be unusual among the courses found.
- Plan for free-tier friction (rate limits, daily credits, deploy steps that need billing) as teaching content: when to switch tools, how to save work to GitHub, how to deploy for free (e.g., GitHub Pages or Netlify, as in Scrimba's deploy step).

### Gaps
- Current (Sept 2026) free-tier quotas for Gemini CLI, AI Studio, Replit, Lovable, Cursor Hobby, Copilot Free and ChatGPT/Claude free were not verified here (outside this note's scope; see the tools research notes).
- No course was found that publishes a "free tools only" guarantee or a tool-cost table for learners.
