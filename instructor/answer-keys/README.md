> [!CAUTION]
> **If your copy of this repository is public, these keys are public too**, and so are the planted bugs in the starter kits. Students can find them with one search. Two ways to cope:
>
> - **Vary the bugs each cohort.** Use the bug menu in the Debug Clinic key to swap in different bugs before you publish the kit as a template ([pre-cohort checklist](../pre-cohort-checklist.md#t-6-weeks-decide-and-set-up)). Keep the new answers in a private place, such as a private repository or your learning platform.
> - **Grade the explanation, not the fix.** The Debug Clinic and Be the Agent are about *how* the student found the bug. A student who copied a fix can't explain how they would have found it, and the oral walkthroughs check exactly that.

## How to use the keys

- **TAs:** read the key before the studio, and do the activity yourself first without it. You'll give better hints if you remember where you got stuck.
- **During the activity:** don't give answers. Use the hint ladder in the [course tutor](../course-tutor.md#the-tutor-prompt), and the kit's hint cards.
- **Self-paced learners:** try each activity first, with the AI off. Then use the hint cards, then tutor mode. Open the key last, to check your reasoning, not to replace it.
